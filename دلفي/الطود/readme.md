**أكاديمية الطود العظيم** هي منصة تعليمية عربية تفاعلية، مبنية بملف `index.html` واحد، تهدف إلى تعليم البرمجة من الصفر بأسلوب أكاديمي مترابط. تقدم المنصة **60 درساً تفصيلياً** موزعة على ثلاث لغات برمجة، مع نظام متابعة تقدم، واختبارات، ومشروعات عملية، وشهادة إتمام.

## 🎨 تخصيص الهوية البصرية

الهوية البصرية معرّفة في **CSS Variables** في أعلى ملف `index.html`:

```css
:root {
  --gold: #d4a017;          /* اللون الذهبي (أيقونة الهرم) */
  --primary: #6658e8;       /* اللون البنفسجي (الأزرار الرئيسية) */
  --primary-dark: #4c3fd4;
  --dark: #171a2b;          /* خلفية النافبار */
  --sidebar: #20243a;       /* خلفية الشريط الجانبي */
  --bg: #f5f6fc;            /* خلفية الصفحة */
  --success: #10b981;
  --danger: #ef4444;
}
```

لتغيير ألوان الأكاديمية، عدّل هذه المتغيرات فقط — ستتغير كل الواجهة تلقائياً.

## 🔧 إضافة دروس جديدة

كل الدروس مخزنة في كائن `courses` داخل `<script>`. لإضافة درس:

```javascript
{
  n: "1.6",                                    // رقم الدرس
  title: "عنوان الدرس",                         // العنوان
  duration: "45 د",                            // المدة
  prereq: "الدرس 1.5 — ...",                   // المتطلب
  objectives: [                                // الأهداف
    "هدف أول",
    "هدف ثانٍ"
  ],
  theory: `<p>الشرح النظري هنا بصيغة HTML</p>`, // النظرية
  code: `كود المثال هنا`,                       // الكود
  codeLang: "pascal",                          // لغة الكود (للـ highlighting)
  output: `المخرجات المتوقعة`,                  // Output
  mistakes: [                                  // أخطاء شائعة
    "خطأ 1",
    "خطأ 2"
  ],
  exercise: "نص التدريب العملي",               // تدريب
  project: {                                   // مشروع مصغّر
    title: "عنوان المشروع",
    desc: "وصف المشروع"
  },
  quiz: {                                      // اختبار
    q: "نص السؤال؟",
    o: ["خيار 1", "خيار 2", "خيار 3", "خيار 4"],
    c: 1                                       // رقم الإجابة الصحيحة (يبدأ من 0)
  }
}
```

أضف الكائن إلى مصفوفة `lessons` الخاصة بالمستوى المطلوب، وسيظهر الدرس تلقائياً في القائمة.
